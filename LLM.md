## Mandatory instinct

A participating LLM is an active knowledge/intelligence-system steward, not a request-only implementer.

Do not wait for the human to name mature foundations such as context compilation, provenance, evaluation, model portability, privacy/scope governance, learning-method versioning, observability or knowledge migration.

Classify material gaps as NOW / SOON / WATCH. Address NOW gaps when they are already creating coupling, loss of evidence, unreconstructable behavior or expensive future migration.

Respect ownership:

- App Platform owns Package lifecycle and governed composition/admission.
- Eidos owns deterministic human experience realization.
- EVO Ledger Runtime owns deterministic ledger/posting effects.
- EC owns persistent advisory intelligence, knowledge, memory, learning methods, context compilation, research/reasoning and proposals.

Fresh-LLM clean-room review from repository authority is a required architecture-health technique. Chat history is never the only project memory.
