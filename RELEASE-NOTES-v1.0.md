# EC v1.0 Release Notes

EC v1.0 establishes the first coherent, executable Manufacturing Intelligence Reference System.

It preserves the v0.9 end-to-end intelligence lifecycle and adds manufacturing decision pre-assessment,
five scenario playbooks, a manufacturing semantic-domain model, explicit knowledge-promotion governance,
scope authorization, scenario benchmarks, and machine-readable readiness evidence.

Version semantics: v1.0 is reference-system maturity, not environment-specific production certification.
Known certification gaps remain visible by design and are documented in docs/11-PRODUCTION-CERTIFICATION.md.
