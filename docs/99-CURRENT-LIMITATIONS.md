# Current Limitations of v0.1

- in-memory repository is reference-only; PostgreSQL adapter is not implemented yet;
- external web research adapters are interfaces/policies only;
- no actual LLM provider adapter is shipped;
- no durable workflow engine adapter is shipped;
- graph/vector/search/analytics stores are deployment route placeholders, not active projections;
- Eidos/EVO adapters define boundaries but are not bound to production endpoints;
- Industry Pack contains only a small manufacturing seed.

These are deliberate: contracts and irreversible boundaries are being stabilized before infrastructure is cemented.
