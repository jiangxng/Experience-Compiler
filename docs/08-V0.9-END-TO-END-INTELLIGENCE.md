# EC v0.9 — End-to-End Intelligence Reference Lifecycle

v0.9 closes the first executable intelligence lifecycle:

EVO-derived/enterprise knowledge → governed canonical records → hybrid retrieval → Context Compiler →
replaceable model → Decision Draft → Eidos semantic Experience Proposal → observed Outcome →
candidate Lesson → Pattern Candidate.

The lifecycle deliberately stops short of autonomous EVO execution. Business commands remain owned and
authorized by EVO. Eidos validates/realizes experience. EC owns understanding, evidence, learning and proposals.

New quality controls include contradiction detection and decision-readiness assessment. Pattern mining is
cohort-based and conservative: repeated observations create candidates, not universal truth.
