# EC v0.7 Reference System

This release is the first executable persistence/retrieval/context/research/learning reference system.

## Real in this release
- durable SQLite canonical reference repository
- content-addressed immutable filesystem evidence archive
- deterministic hybrid lexical/semantic retrieval
- adaptive context compilation with explicit budgets
- provider-neutral model gateway plus deterministic test provider
- active research pipeline from acquired documents to governed candidate claims
- Decision -> Outcome -> candidate Lesson loop
- EVO/Eidos reference gateways and semantic contracts
- manufacturing reference scenario and regression tests

## Deliberately not claimed
SQLite, hashed-vector retrieval and filesystem evidence are reference implementations, not the intended hyperscale production data plane. Production PostgreSQL/object storage/search/vector/graph services remain replaceable adapters. Real network crawling and commercial LLM credentials are never embedded in the repository.
