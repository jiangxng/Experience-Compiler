# Terminology

- **Claim**: assertion from a source, not yet accepted as fact.
- **Fact**: governed proposition accepted within a scope and time interval.
- **Case**: concrete situation.
- **Decision**: selected action among alternatives.
- **Outcome**: observed result after a decision/action.
- **Lesson**: interpretation derived from one or more cases.
- **Pattern**: repeatable regularity with evidence and evaluation.
- **Learning Strategy**: versioned method for acquiring/evaluating knowledge.
- **Context Pack**: bounded task-specific projection supplied to a model.
- **Projection**: rebuildable search/vector/graph/analytics representation.
