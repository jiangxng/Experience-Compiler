# Active Learning and External Research

External learning is an extension plane with a first-class protocol. EC may detect stale knowledge, contradictions, missing evidence, new regulations or pattern drift and schedule research.

Crawler/search/browser/API adapters must obey source access rights, robots directives where applicable, contractual/licensing limits, privacy, jurisdiction and organization policy. Do not bypass access controls. Preserve raw evidence and retrieval metadata where legally permitted.

Pipeline: Knowledge Gap -> Research Plan -> Source Discovery -> Acquisition -> Hash/Archive -> Claim Extraction -> Entity/Time Resolution -> Corroboration -> Contradiction Analysis -> Candidate Knowledge -> Review/Policy Promotion.
