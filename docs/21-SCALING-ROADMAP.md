# Scaling Roadmap

1. Vertical scale while operational simplicity dominates.
2. Separate canonical DB/object storage/search/vector/analytics.
3. Add HA/replication and event-driven projection.
4. Partition by tenant/domain/time where measured.
5. Introduce distributed index clusters.
6. Federate sovereign/air-gapped EC cells with controlled knowledge exchange.

Projection services can be rebuilt or replaced without changing canonical KnowledgeRecord IDs.
