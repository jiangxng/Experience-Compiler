# EC v0.8 — Integration & Intelligence Runtime

v0.8 moves the v0.7 reference loop toward real infrastructure without claiming that external systems already expose APIs they have not finalized.

## Added
1. PostgreSQL canonical repository adapter aligned to the versioned migration.
2. Projection fan-out semantics: canonical truth is durable; search/vector/graph projections are rebuildable.
3. OpenAI-compatible model-provider adapter behind EC's model gateway.
4. Explicit-URL HTTP research acquisition adapter with size/time/access boundaries.
5. Configurable JSON/HTTP EVO and Eidos preview gateways.
6. Integration contract tests using fake transports, so EC can converge against authoritative APIs without hard-coding implementation internals.

## Important boundary
The HTTP paths under `integration/http.py` are preview defaults. They are configuration, not constitutional API ownership. EVO owns business truth/commands; Eidos owns capability validation/runtime.

## Production route
Use PostgreSQL as canonical relational governance store; object storage for immutable evidence; dedicated search/vector/graph/analytics projections as scale demands. Projection loss must be recoverable from canonical/evidence/event history.
