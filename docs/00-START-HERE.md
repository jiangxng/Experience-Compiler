# Start Here

This release establishes the durable EC boundaries. Do not begin by adding a vector database or an agent framework. Begin with the Constitution, canonical data types, scope/provenance rules, and the integration contracts.

## Operator path
1. Run tests.
2. Run `ec doctor`.
3. Run manufacturing demo.
4. Read hardware/capacity and deployment docs before enabling external stores.

## Architect path
Read Constitution -> Architecture -> Data/Scale -> Security -> Learning -> EVO/Eidos -> LLM replacement -> roadmap.
