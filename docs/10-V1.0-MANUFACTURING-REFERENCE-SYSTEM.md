# EC v1.0 — Manufacturing Intelligence Reference System

## Meaning of v1.0
v1.0 means the *reference-system contract* is coherent and executable. It does **not** mean a production
deployment has passed customer-specific HA, DR, security, load, regulatory or authoritative EVO/Eidos API certification.

The system now has:
- persistent governed knowledge and evidence boundaries
- hybrid retrieval and bounded context compilation
- replaceable model gateway
- active research candidate pipeline
- explicit promotion governance
- contradiction/readiness controls
- Decision → Outcome → Lesson → Pattern learning
- five manufacturing reference decision families
- deterministic manufacturing option pre-assessment
- Eidos semantic experience planning
- EVO command boundary
- readiness report that distinguishes executable reference maturity from deployment certification

## Reference scenarios
1. Critical material shortage.
2. Capacity overload.
3. Quality hold.
4. Machine downtime risk.
5. Fulfillment allocation.

These scenarios are regression anchors for future Industry Pack growth.
