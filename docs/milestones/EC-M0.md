# EC-M0 — Contract & Form Compilation Foundation

Acceptance criteria:
- authoritative context docs exist;
- EVO and Eidos integration boundaries are documented;
- semantic input contract is versioned;
- UIDL output contract is versioned;
- sales-order confirmation compiles deterministically;
- unsupported semantics fail closed;
- build and tests pass without runtime dependencies.

Not in scope: dynamic AI layout planning, report compiler, chart compiler, live EVO transport, Eidos rendering.
