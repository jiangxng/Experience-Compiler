# EC v0.9 Release Notes

v0.9 closes the first executable enterprise-intelligence lifecycle:
governed knowledge → hybrid retrieval → context compilation → replaceable model → decision draft →
Eidos semantic proposal → observed outcome → candidate lesson → pattern candidate.

Added contradiction detection, decision-readiness quality assessment, conservative cohort pattern mining,
manufacturing intelligence orchestration, five reference manufacturing decision scenarios and expanded
process semantics.

This is still a reference lifecycle, not a claim of production certification. See docs/09-V1-READINESS-GATE.md.
